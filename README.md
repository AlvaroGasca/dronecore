# DroneCore

Guía estática, didáctica y responsive sobre drones en España. Está construida únicamente con HTML5, CSS3 y JavaScript Vanilla.

## Desarrollo local

Abre `index.html` en el navegador o sirve esta carpeta con cualquier servidor estático. No requiere instalación ni proceso de compilación.

## Contenido

- Tecnología y componentes de drones
- Normativa, formación y planificación del espacio aéreo
- Recursos oficiales y preguntas frecuentes

La guía es divulgativa. Consulta siempre AESA, ENAIRE Drones y la normativa vigente antes de realizar una operación.

## Publicación

Antes de publicar, sustituye `https://example.com/` por el dominio definitivo en `sitemap.xml`.
